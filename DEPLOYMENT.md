# Deployment Guide - VPS Deployment

This guide provides step-by-step instructions for deploying the Alpha Partners application to your VPS.

## 📋 Prerequisites

- VPS with Ubuntu 20.04+ or similar Linux distribution
- SSH access to your VPS
- Domain name pointing to your VPS IP
- Node.js 16+ installed on VPS
- npm or yarn package manager
- Basic terminal/SSH knowledge

## 🚀 Deployment Steps

### 1. SSH into Your VPS

```bash
ssh root@your-vps-ip
# or with specific user
ssh username@your-vps-ip
```

### 2. Install System Dependencies

```bash
# Update system packages
sudo apt update && sudo apt upgrade -y

# Install Node.js and npm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Install git
sudo apt install -y git

# Install Nginx
sudo apt install -y nginx

# Install certbot for SSL
sudo apt install -y certbot python3-certbot-nginx

# Install sqlite3
sudo apt install -y sqlite3

# Verify installations
node --version
npm --version
```

### 3. Clone Your Repository

```bash
# Create app directory
sudo mkdir -p /var/www/alpha-partners
sudo chown -R $USER:$USER /var/www/alpha-partners
cd /var/www/alpha-partners

# Clone repository
git clone https://github.com/YOUR_USERNAME/alpha-partners.git .
# or if using git over SSH
git clone git@github.com:YOUR_USERNAME/alpha-partners.git .
```

### 4. Install Dependencies

```bash
cd /var/www/alpha-partners
npm install

# Build frontend
npm run build
```

### 5. Configure Environment Variables

```bash
# Create .env file
nano /var/www/alpha-partners/.env
```

Add the following (adjust as needed):

```env
# Server
NODE_ENV=production
PORT=5000

# Database
DATABASE_PATH=/var/www/alpha-partners/data/app.db

# JWT
JWT_SECRET=GENERATE_RANDOM_STRING_HERE_32_CHARS_MIN

# Frontend API URL (change to your domain)
VITE_APP_API_URL=https://alphapartners.ca/api

# Site Configuration
SITE_NAME=Alpha Partners Investment Inc.
SITE_URL=https://alphapartners.ca
CONTACT_EMAIL=contact@alphapartners.ca
CONTACT_PHONE=+1 (XXX) XXX-XXXX
```

To generate a secure JWT_SECRET:

```bash
openssl rand -hex 32
```

### 6. Create Data Directory

```bash
mkdir -p /var/www/alpha-partners/data
chmod 755 /var/www/alpha-partners/data
chmod 755 /var/www/alpha-partners
```

### 7. Test Backend Server

```bash
cd /var/www/alpha-partners
npm run server
```

Check if API is running:
```bash
curl http://localhost:5000/api/health
```

Stop the server (Ctrl+C) when verified.

### 8. Set Up PM2 (Process Manager)

```bash
# Install PM2 globally
sudo npm install -g pm2

# Create ecosystem config
cat > /var/www/alpha-partners/ecosystem.config.js << 'EOF'
module.exports = {
  apps: [
    {
      name: 'alpha-partners-api',
      script: './server.ts',
      interpreter: './node_modules/.bin/tsx',
      env: {
        NODE_ENV: 'production',
        PORT: 5000,
      },
      instances: 'max',
      exec_mode: 'cluster',
      restart_delay: 4000,
      max_memory_restart: '1G',
      error_file: './logs/err.log',
      out_file: './logs/out.log',
      log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
    },
  ],
};
EOF

# Create logs directory
mkdir -p /var/www/alpha-partners/logs
chmod 755 /var/www/alpha-partners/logs

# Start with PM2
cd /var/www/alpha-partners
pm2 start ecosystem.config.js

# Save PM2 process list and set to start on boot
pm2 save
pm2 startup
# Follow the output - it will give you a command to run with sudo
```

### 9. Configure Nginx as Reverse Proxy

```bash
# Create Nginx config
sudo nano /etc/nginx/sites-available/alpha-partners
```

Add this configuration:

```nginx
# Redirect HTTP to HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name alphapartners.ca www.alphapartners.ca;
    return 301 https://$server_name$request_uri;
}

# HTTPS server
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name alphapartners.ca www.alphapartners.ca;

    # SSL certificates (will be generated by certbot)
    ssl_certificate /etc/letsencrypt/live/alphapartners.ca/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/alphapartners.ca/privkey.pem;

    # SSL configuration
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # Security headers
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;

    # Gzip compression
    gzip on;
    gzip_types text/plain text/css text/javascript application/json application/javascript;
    gzip_min_length 1000;

    # Logs
    access_log /var/log/nginx/alpha-partners.access.log;
    error_log /var/log/nginx/alpha-partners.error.log;

    # Static files cache
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Frontend
    location / {
        root /var/www/alpha-partners/dist;
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "public, max-age=3600";
    }

    # API backend
    location /api/ {
        proxy_pass http://127.0.0.1:5000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # Block admin paths from direct access (should go through reverse proxy)
    location /admin {
        root /var/www/alpha-partners/dist;
        try_files $uri $uri/ /index.html;
        add_header X-Robots-Tag "noindex, nofollow" always;
    }

    # Deny access to sensitive files
    location ~ /\. {
        deny all;
    }

    location ~ ~$ {
        deny all;
    }

    location ~ \.env {
        deny all;
    }
}
```

Enable the site:

```bash
sudo ln -s /etc/nginx/sites-available/alpha-partners /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default  # Remove default site if present

# Test Nginx configuration
sudo nginx -t

# Restart Nginx
sudo systemctl restart nginx
```

### 10. Set Up SSL Certificate with Let's Encrypt

```bash
sudo certbot --nginx -d alphapartners.ca -d www.alphapartners.ca

# Auto-renew certificates (runs daily)
sudo systemctl enable certbot.timer
sudo systemctl start certbot.timer

# Test renewal
sudo certbot renew --dry-run
```

### 11. Configure Firewall

```bash
# Enable UFW
sudo ufw enable

# Allow SSH
sudo ufw allow 22/tcp

# Allow HTTP and HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Check status
sudo ufw status
```

### 12. Set Up Automated Backups

```bash
# Create backup script
sudo nano /usr/local/bin/backup-alpha-partners.sh
```

Add:

```bash
#!/bin/bash
BACKUP_DIR="/backups/alpha-partners"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
DB_FILE="/var/www/alpha-partners/data/app.db"

mkdir -p $BACKUP_DIR

# Backup database
cp $DB_FILE $BACKUP_DIR/app.db.backup_$TIMESTAMP

# Compress and keep only last 30 days
find $BACKUP_DIR -name "*.backup_*" -mtime +30 -delete

# Upload to remote storage (optional)
# aws s3 cp $BACKUP_DIR/app.db.backup_$TIMESTAMP s3://your-bucket/backups/

echo "Backup completed: $TIMESTAMP"
```

Make executable:

```bash
sudo chmod +x /usr/local/bin/backup-alpha-partners.sh
```

Add to crontab (runs daily at 2 AM):

```bash
sudo crontab -e

# Add this line:
0 2 * * * /usr/local/bin/backup-alpha-partners.sh >> /var/log/alpha-partners-backup.log 2>&1
```

### 13. Monitor Logs

```bash
# Application logs
pm2 logs

# Nginx access logs
sudo tail -f /var/log/nginx/alpha-partners.access.log

# Nginx error logs
sudo tail -f /var/log/nginx/alpha-partners.error.log

# System logs
sudo journalctl -u nginx -f
```

## 📊 Post-Deployment Verification

### Check Application Status

```bash
# Check if backend is running
pm2 status

# Check if Nginx is running
sudo systemctl status nginx

# Check if domain is accessible
curl -I https://alphapartners.ca

# Check API health
curl https://alphapartners.ca/api/health
```

### Create First Admin User

```bash
# Test API endpoint
curl -X POST https://alphapartners.ca/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@alphapartners.ca",
    "password": "SecurePassword123!",
    "role": "admin"
  }'
```

Then login at: `https://alphapartners.ca/admin/login`

```bash
# Check SSL certificate
curl -I https://alphapartners.ca

# Verify security headers
curl -I https://alphapartners.ca | grep -E "Strict-Transport|X-Content"

# Check robots.txt
curl https://alphapartners.ca/robots.txt
```

## 🆘 Troubleshooting

### Port 5000 Already in Use

```bash
# Find process using port 5000
lsof -i :5000

# Kill the process
kill -9 <PID>

# Or restart PM2
pm2 restart alpha-partners-api
```

### Database Locked Error

```bash
# Stop the application
pm2 stop alpha-partners-api

# Wait a moment, then restart
pm2 start ecosystem.config.js
```

### Nginx Not Serving Frontend

```bash
# Check Nginx config syntax
sudo nginx -t

# Check file permissions
ls -la /var/www/alpha-partners/dist/

# Make sure index.html exists
ls /var/www/alpha-partners/dist/index.html
```

### SSL Certificate Issues

```bash
# Check certificate status
sudo certbot status

# Renew certificate manually
sudo certbot renew --force-renewal

# Check certificate expiry
openssl x509 -enddate -noout -in /etc/letsencrypt/live/alphapartners.ca/cert.pem
```

## 📈 Monitoring and Alerts

Consider setting up monitoring for:

1. **Uptime Monitoring**
   - Use Uptime Robot or similar service
   - Monitor https://alphapartners.ca/api/health

2. **Error Tracking**
   - Optional: Set up Sentry integration
   - Monitor error logs via: `pm2 logs`

3. **Performance Monitoring**
   - Use Google Lighthouse for periodical checks
   - Monitor Nginx access logs for slow requests

4. **Security Monitoring**
   - Review admin activity logs weekly
   - Check access logs for suspicious patterns
   - Monitor failed login attempts
