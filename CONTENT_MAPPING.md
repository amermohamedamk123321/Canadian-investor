## 🎯 Mapping Structure

Each entry shows:
- **PDF Section**: Where content comes from in the PDF
- **Target Page**: Public URL where it appears
- **Admin Location**: Where to edit it
- **Content Type**: Text block, list, form, etc.
- **Status**: Not Started / In Progress / Complete
- **Notes**: Special instructions or formatting requirements

## 📋 Content Types & Formats

### Text Blocks
- Use `<h2>` for section headings
- Use `<p>` for paragraphs
- Keep paragraphs to 2-3 sentences max
- Use `<strong>` for emphasis, not all caps

### Lists
- Use `<ul><li>` for unordered lists
- Use `<ol><li>` for ordered/numbered lists
- Keep each list item to one line if possible

### Asset Types (for Canadian Investors)
Examples:
- Residential
- Commercial
- Multi-Family
- Land Development
- Industrial
- Mixed-Use

### Services Audience
- **Both**: Show to Canadian AND International investors
- **Canadian Only**: Show only on Canadian investors page
- **International Only**: Show only on International investors page

## 📝 Notes for Content Editors

- Always preserve exact legal text from PDF (especially disclaimers)
- Format long text as short bullets or numbered lists
- Test links and PDFs after adding them
- Use consistent terminology across all pages
- Avoid marketing claims not in the PDF
- Include contact info in appropriate places
- Remember: Web content = shorter, scannable paragraphs
