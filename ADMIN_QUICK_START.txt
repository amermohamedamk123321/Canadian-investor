================================================================================
                         5-MINUTE QUICK TASKS
================================================================================

1. EDIT PAGE CONTENT
   - Click PAGES → Select page → Edit HTML content → Save Changes

2. ADD INVESTMENT OPPORTUNITY
   - Click OPPORTUNITIES → Create Opportunity → Fill form → Save

3. ADD CANADIAN PROVINCE
   - Click CANADIAN INVESTORS → Add Province → Fill form → Save

4. ADD SERVICE
   - Click SERVICES → Add Service → Fill form → Save

5. UPLOAD SECURITY PDF
   - Click SECURITY PDF → Drag PDF file into upload area → Auto-saves

6. VIEW CONTACT SUBMISSIONS
   - Click SUBMISSIONS → See all inquiries → Update status as needed

7. CREATE NEW ADMIN USER (Super Admin only)
   - Click ADMIN USERS → Create User → Enter email & password → Save

8. CHECK ACTIVITY LOG
   - Click ACTIVITY LOG → See all changes with timestamps & users

================================================================================
                           COMMON FIELDS
================================================================================

SLUG:                URL-friendly name (lowercase, hyphens only)
                     Example: "commercial-real-estate" not "Commercial Real Estate"

TITLE:              Display name shown to public
                     Example: "Investment Opportunities for Canadian Investors"

DESCRIPTION:        Brief text (1-2 sentences)

DETAILS:            Full explanation (can include HTML tags)

AUDIENCE:           For services: Canadian Only / International Only / Both

FEATURED:           Toggle to show on homepage (usually first 3 items)

META DESCRIPTION:   What appears in Google search results (160 chars max)
                     Example: "Explore vetted investment opportunities..."

================================================================================
                        TROUBLESHOOTING QUICK FIX
================================================================================

Can't log in?
  → Check email address and password
  → Ask Super Admin for password reset

Changes not showing?
  → Click REFRESH button
  → Wait 10 seconds for browser cache
  → Clear browser cache (Ctrl+Shift+Delete)

Upload failed?
  → Check file is PDF (for security PDF)
  → Verify file size under 50MB
  → Try different browser

No permissions?
  → Super Admin feature - ask Super Admin for access
  → Editors can only manage content, not users
